- 2026-10-20 · tests — expose changing state on the test hooks as functions; `Object.assign` copies a getter's value once, so a plain property goes stale.
- 2026-10-20 · tests — a test that needs a specific bro must set `S.P.bro` itself (usually Einstein); a new run starts with 10 random bros.
- 2026-10-20 · maps — never hard-code a boss arena column; wrap it in `arenaCol()`, because `slideArena()` moves every arena by the stretch.
- 2026-10-20 · agents — worktree agents can start from old main; tell each agent to reset to the feature branch head before working.
- 2026-10-20 · comments — a `//` comment in the middle of a line cuts off the code after it; put comments at the end of the line.
- 2026-10-20 · tests — some checks are flaky under parallel load; rerun a failing file alone and compare with an older commit before calling it a regression.
- 2026-10-21 · playing — the user plays by opening `science-bros/index.html` as a file; if they "don't see the changes", reopen that exact path with a fresh `?v=` and warn about stale tabs from `.claude/worktrees/`.
- 2026-10-21 · tools — the `gh` on PATH is a broken Anaconda package; use `/opt/homebrew/bin/gh`.
- 2026-10-21 · screenshots — with `window.__SB_TEST__` set there is no game loop, so a headless Chrome page stays black; call `__SB__.startLevel(n)`, step and `render(1)` yourself, then copy the `#game` canvas with `toDataURL`.
- 2026-10-21 · nuke — `crater()` loops rows from `NUKE_HOLE` sizes; a fractional size (7.5) made every row index fractional, typed-array writes were ignored and the core stayed solid. Round loop bounds to whole rows; `bros.js` "it blows a crater" catches it.
- 2026-10-21 · merges — a merge that adds `Math.random()` calls (chunks, dust) shifts the seeded random stream in every test, so balance checks near their limit flip (Mendel 0.72 -> 0.58 of the median, Semmelweis bubble, fizz vs tank). Before blaming the merge, check the same test on each branch alone; fix fragile bots (face the boss, fire at fair range), and use `BOSS_MUL` only for a real weak bro.
- 2026-10-21 · maps — `LW` (560) is only the array size; "end of the map" is `playW` and "how far the arena slides" is `stretchW`. Changing a global width also resizes random maps and bonus modes, which the user did not want.
- 2026-10-21 · tests — a new bro must be added to the hard-coded id and `DESTRUCT` key lists in `weapons_bosses.js` and the count in `bros.js`; many tests also use mission 1 spots (flat start at row 16, lab, tide pools) as fixtures.
- 2026-10-21 · agents — parallel agents share one scratchpad folder; give every scratch file a per-workstream prefix, or one agent overwrites another's scripts.
- 2026-10-21 · timing — with several agents running, load reaches 25-35 and absolute frame-time checks fail on old commits too; measure new vs base back to back on a quiet machine.
- 2026-10-21 · page — the game's window keydown handler calls preventDefault on Tab, Enter, Space and Esc, which breaks page buttons and details/summary; page controls must stop those keys before they reach the window handler (`pageKeys()`).
- 2026-10-21 · ladders — ladder tops now hold the bro (`moveBody`), which moves boss-test bots onto new spots; seeded boss checks can flip. Look at where the bot stands before tuning balance.
- 2026-10-21 · missions — never seed a mission by its level index or hard-code the Citadel's index; inserting two missions shifted both (use `seedN`, `S.nLevels - 1`). Tests that list bosses per level must find the Citadel as the last mission.
- 2026-10-21 · merges — branches that each add content to shared pools (bro lines, signs per mission, fingerprints) collide after merging: a new bro needs its `BRO_LINES`, a new mission its `WIT_SIGNS` and a boss skin; take test fingerprints on the head just before the merge, not on the old base.
- 2026-10-21 · agents — five agents running test batches at once drove the load to 115 and made git time out; tell agents to run tests one at a time and leave the full suite to the lead.
- 2026-10-21 · tests — freeing a cage swaps the bro, so a bot that should play "as Einstein" must reset `S.P.bro` every frame; otherwise adding bros changes which bro the bot ends up with and seeded bot checks flip.
- 2026-10-21 · missions — missions can now be inserted anywhere: every older mission has a fixed `seedN`, Boss Rush maps through the pre-round-6 list, and tests find fixture missions by name or old position. Never index a mission by number in new code or tests.
- 2026-11-08 · game — the chopper waits for every required objective, so killing the boss first looks like nothing happens; the objective list and an arrow now stay up while it waits.
- 2026-11-08 · walls — plain enemy shots already stopped at tiles; "shot through walls" came mainly from `explode()` hurting by distance alone.
- 2026-11-08 · tests — inserting a mission shifts hard-coded level indices in many tests; walking-bot tests must remove `tanksuit`, whose 50 px/s only slows them. In zsh, `echo == x` fails; quote it.
- 2026-11-08 · flaky — enemies_new.js sapper digging fails about 2 of 5 runs on 11f8070 too; levels.js bot flips on several missions; run frame-time checks alone.
- 2026-11-09 · hub — the handover hooks only work when the session starts in this repo; a session started one level up (`Documents/sciforce`) writes no `.handover/`.
- 2026-11-10 · agents — three agents in detached worktrees (scratchpad, baseline diff staged, no commits) merged with `git merge-file` against the staged base: one conflict in three workstreams when each agent had named functions and a fixed anchor line for its test hook. A conflict where two inserts share a closing brace needs the brace added back by hand; run a syntax check after every merge.
- 2026-11-10 · tests — a test must not read the main checkout by absolute path as its "unmodified game"; after integration it compares the file with itself. Record a fingerprint instead (`r8_records.js` check 9).
- 2026-11-10 · timing — under outside load (load average 170 to 380) every "under 3 ms a frame" check fails on the old build too; compare old and new interleaved in one process (same seed, same fight) instead of reading absolute numbers.
- 2026-11-10 · screenshots — a file:// copy of the game with `window.__SB_TEST__ = true` injected and a driver script appended renders any screen in headless Chrome (`--headless=new --screenshot`, own `--user-data-dir`); render twice with a rising `t`, since the round 8 fade starts at the first render after a state change.
- 2026-11-11 · maps — "the campaign map is 560 wide" is no longer true: width follows the region (`STRETCH_OF`). Tests must read `S.stretchW()` and `S.playW()` of the level they started, never `S.STRETCH` or 560, and bots must take trigger columns from the boss (`B.trig - 100`), not from fixed numbers.
- 2026-11-11 · maps — changing how many detours a stretch gets changes the cage total (`CAGES_TOTAL`, 150 -> 131) and with it the unlock thresholds; `BRO_AT` is now scaled from the total. Recount with `tests/regions_unlock.js` after any stretch change.
- 2026-11-11 · tests — a test bro with `P.inv = 1e9` is skipped by falling blocks, so blocks cut by a suit landed inside it and wedged it; player-cut blocks now shatter on a suit even while the bro cannot be hurt. Check for "invulnerable test bro" artefacts before trusting a stuck bot.
- 2026-11-11 · tests — once a campaign level has been played in a test context, `runSaved` is set and the title menu has CONTINUE in front: index the title with `S.titleItems()`, or call `S.clearRun()` first; `S.TITLE_MENU` indices are off by one then.
- 2026-11-11 · timing — with Xcode builds running (load average above 400) one test file takes 30 s to 11 min; run test groups against a snapshot copy of the game in the background and keep editing the real file.
- 2026-11-11 · user — "maps are missing" meant the mission numbers on the world map jumped (12 to 19): numbers came from the `LEVELS` index, not the map order. Show `missionNo()`; ask what is seen on screen before hunting for missing content.
- 2026-11-11 · user — the DARK modifier was unplayable ("can't see"): a setting made for a 10 s event must not be reused for a whole mission. The graphics pass had been told to leave DARK untouched; that instruction was wrong.
- 2026-11-11 · tests — a balance check on one seed can sit on a bimodal result (pogo and fizz against the tank: 10.8 hp/s or about 5 hp/s depending on the tank's pattern); any change to the random stream flips it. Use the median of several seeds.
- 2026-11-11 · performance — the per-character outline passed its cost check on quiet scenes (+0.27 ms) and cost 10 ms a frame with 18 quacks on screen. Measure new render code on the busiest scene (INSANE / 300%, densest 30 columns), per function, in real Chrome (`scratchpad/prof/run.sh` wrapped every draw function with a timer); the Node tests stub the canvas and see none of it.
- 2026-11-11 · performance — in Chrome a canvas-to-canvas `drawImage` per entity is the expensive thing, not the number of shapes; batch into one layer per frame.
- 2026-11-11 · tools — macOS `open "file:///...index.html?x=1"` drops the query string, so the page loads without it (the user got the title screen instead of the linked mission). Open a small page that does `location.replace(...)` with the full address instead, and check the result before telling the user it is open.
- 2026-11-11 · user — "if I blow up too much ground I fall in and die" was the old rule that everything below row 22 outside a zone is off the map, plus a steel layer at row 21 under all ground. Destructible ground must lead somewhere survivable.
